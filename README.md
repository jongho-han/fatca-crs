# FATCA·CRS 본인확인 화면 (웹 / 앱)

디자인 캔버스 「계약관계자 정정 화면」의 **FATCA-CRS 단독(F1–F5)** 과 **인터넷고객창구 PC(P1–P5)** 화면을 실제로 동작하는 HTML/CSS/JS로 구현했습니다.
빌드 도구나 프레임워크 없이 정적 파일로 동작합니다.

```
index.html               진입 페이지 (앱 / 웹 선택)
app/                     모바일 앱·웹뷰 화면 (F1–F5)
web/                     인터넷고객창구 PC 레이어팝업 (P1–P5)
assets/js/fatca-core.js  공통 상태 · 업무 규칙 · 검증 · 전송 데이터
```

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/` 를 엽니다. 웹 화면은 진입 시 레이어팝업이 바로 열리고, `web/?closed` 로 열면 닫힌 상태로 시작합니다.

## 흐름

1. **본인확인서 작성**: 고객 인적사항(자동 입력), ① 미국인 여부(예 → 시민권자/영주권자/거주자 체크), ② 해외 조세목적상 거주자 여부.
   국적이 한국이 아니거나 ①·② 중 하나라도 '예'이면 ③ 영문성명과 3. 납세자 정보(거주지국 최대 2개, 영문주소, TIN 또는 미기재 사유)가 나타나고 필수가 됩니다.
2. **증빙서류 첨부**: 필수 서류를 모두 등록해야 '다음'이 활성화됩니다. 앱은 촬영하기/앨범에서 선택, 웹은 파일찾기.
3. **본인인증**: 작성 내용 확인 후 인증 방법 선택 → 제출 → 완료 화면.

## 검증 규칙 (`validateStep1`)

| 항목 | 규칙 |
| --- | --- |
| ① '예' | 해당 사항 1개 이상 체크 |
| 영문성명 | 성·이름 필수, 영문 대문자로 자동 변환 |
| 거주지국 | 대한민국 제외, 중복 불가, 미국인은 미국 포함 필수 |
| 영문주소 | 영문·숫자·기호만, 우편번호(숫자 3자리 이상) 포함 |
| 납세자번호 | 미국: SSN/ITIN 9자리 숫자(하이픈 자동 제거). 미국 외: TIN 또는 미기재 사유, '기타'는 사유 입력 |
| 증빙파일 | JPG·PNG·PDF, 파일당 최대 `MAX_FILE_MB`(10MB) |

## 디자인과 다르게 정한 부분 / 확인 필요

- **증빙서류 구성**: 주민등록등본은 항상, 납세자번호 증명서는 납세자 정보 작성 대상일 때만 필수로 했습니다. (디자인은 모바일에서 서류 ①을 '기타 증명서', PC에서 '주민등록등본'으로 표기해 PC 기준으로 통일)
- **파일 용량 한도**: 디자인의 `[용량]` 자리 — `assets/js/fatca-core.js` 의 `MAX_FILE_MB` 로 조정.
- **인증 수단**: 앱은 간편인증·공동인증서·금융인증서, 웹은 디자인대로 간편인증·공동인증서.
- **연동 지점**: 고객 정보는 `SAMPLE_CUSTOMER`(예시), 제출은 `submit()` 의 `TODO` 위치에서 인증 모듈 호출 후 `buildPayload(state)` 를 서버로 전송하도록 연결하면 됩니다. 현재는 콘솔 출력 후 완료 화면으로 이동합니다.
- 캔버스의 「계약관계자 정정 전체 흐름(01–08)」은 이번 범위에 포함하지 않았습니다.
